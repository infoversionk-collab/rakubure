プライバシーポリシー

Version-K（以下「当方」といいます。）は、 当方が提供する「楽ブレ」（以下「本サービス」といいます。）における 利用者の個人情報等の取り扱いについて、以下のとおり定めます。

第1条　基本方針

当方は、個人情報の保護に関する法律その他の関係法令を遵守し、 利用者の個人情報を適切に取り扱うよう努めます。

本ポリシーは、本サービスの利用に関連して当方が取得する情報の 取り扱いについて定めるものです。

第2条　取得する情報

当方は、本サービスの提供にあたり、以下の情報を取得する場合があります。

  • 氏名、メールアドレス等の利用者に関する情報
  • アカウントの登録情報および認証に関連する情報
  • 履歴書、職務経歴書、推薦状等の作成に必要な情報
  • BPOスキルシート等の作成に必要な情報
  • 利用者がアップロードしたファイルおよび入力内容
  • サービスの利用履歴、操作履歴、エラー情報等
  • お問い合わせ時に提供された情報
  • 決済状況や契約管理に必要な情報
  • その他、本サービスの提供に必要な情報

実際に取得する情報は、利用する機能や登録方法によって異なります。

第3条　個人情報の利用目的

当方は、取得した情報を以下の目的で利用します。

  • 本サービスの提供および運営
  • アカウントの登録、本人確認、認証および利用者管理
  • 履歴書、職務経歴書、推薦状等の作成支援
  • BPOスキルシート等の作成支援
  • アップロードされたファイルの解析および文章生成
  • 利用料金の請求、決済確認および契約管理
  • お問い合わせへの対応
  • 不正利用の防止およびセキュリティの確保
  • 障害対応、品質改善および機能改善
  • 重要なお知らせやサービスに関する連絡
  • 法令上の義務への対応

上記の利用目的を変更する場合は、法令に従って必要な対応を行います。

第4条　履歴書等の入力情報の取り扱い

本サービスでは、履歴書、職務経歴書、推薦状および BPOスキルシート等の作成支援を目的として、 利用者が入力またはアップロードした情報を取り扱います。

これらの情報には、氏名、住所、連絡先、学歴、職歴、 資格その他の個人情報が含まれる場合があります。

当方は、これらの情報を本サービスの提供、書類作成、 利用者からの問い合わせ対応その他適法な目的の範囲内で取り扱います。

利用者は、本サービスに入力またはアップロードする情報について、 必要な権限を有していることを確認したうえで利用するものとします。

他人の個人情報を入力する場合は、適用される法令に従い、 必要な同意や権限を確保してください。

第5条　外部サービスの利用

当方は、本サービスの提供、認証、データ保存、書類生成、 AIによる解析および文章生成、決済等のために、 外部のサービスを利用する場合があります。

利用する場合があるサービスの例は以下のとおりです。

  • Googleの各種サービス
  • Google Apps Script
  • GoogleスプレッドシートおよびGoogleドキュメント
  • FirebaseおよびFirestore
  • Gemini等のAIサービス
  • Square等の決済サービス
  • GitHub Pages等のWebサイト公開サービス

これらは利用する場合があるサービスの例であり、 実際の利用状況は本サービスの機能や構成によって異なります。

外部サービスに情報を送信する場合は、本サービスの提供に必要な範囲で行い、 利用するサービスの規約、プライバシーポリシーその他の条件を踏まえて 適切に取り扱います。

AIサービスを利用して書類の解析や文章生成を行う場合、 入力された情報が処理のために当該サービスへ送信されることがあります。 実際の送信先や処理内容については、利用する機能に応じて確認できるようにします。

第6条　第三者提供

当方は、法令に基づく場合など、個人情報保護法その他の法令で 認められる場合を除き、本人の同意なく個人データを第三者に提供しません。

外部サービス事業者への情報の送信については、 その実態や契約関係に応じて、法令上必要な対応を行います。

第7条　個人情報の安全管理

当方は、取り扱う個人情報について、漏えい、滅失、毀損、 不正アクセスその他のリスクを防止するため、 必要かつ適切な安全管理措置を講じるよう努めます。

また、利用する外部サービスの設定やアクセス権限についても、 情報の性質や利用目的に応じて適切に管理します。

第8条　個人情報の保存期間と削除

当方は、利用目的の達成に必要な範囲で個人情報を保存し、 保存する必要がなくなった場合には、法令上保存が必要な場合を除き、 適切な方法で削除または利用停止等を行うよう努めます。

ただし、外部サービス、バックアップ、法令上の保存義務等により、 削除が反映されるまでに一定の時間を要する場合があります。

利用者が本サービス上で作成・保存した書類については、 保存先や利用機能によって削除方法が異なる場合があります。

第9条　個人情報の開示・訂正・利用停止等

利用者本人から、保有個人データの開示、訂正、追加、削除、 利用停止、消去、第三者提供の停止等について法令に基づく請求があった場合、 本人確認を行ったうえで、法令に従って適切に対応します。

具体的な手続きについては、下記のお問い合わせ先までご連絡ください。

第10条　Cookie等の利用

本サービスまたは利用する外部サービスでは、 認証状態の維持、セキュリティの確保、利便性の向上等を目的として、 Cookieその他の類似技術が使用される場合があります。

実際の使用状況は、本サービスの構成および利用する外部サービスによって異なります。

第11条　未成年者の利用

未成年者が本サービスを利用する場合は、 必要に応じて法定代理人等の同意を得たうえで利用してください。

第12条　プライバシーポリシーの変更

当方は、法令の改正、本サービスの機能変更その他の事情に応じて、 本ポリシーを変更する場合があります。

重要な変更を行う場合は、法令に従い、 本サービス上での掲示その他適切な方法で利用者に周知します。
